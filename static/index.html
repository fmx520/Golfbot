How It Works

What is Dry Run?

Dry Run searches for tee times but does not book anything. Use it to preview availability and confirm your filters are correct before committing to a real booking.

What is Sniper Mode?

Sniper Mode is designed to beat other bots when courses release tee times at a fixed time (e.g., 7:00 PM). It pre-authenticates your session, then at release time polls the ForeUp API every 200ms (5 requests/second) until a matching slot appears. The booking fires within milliseconds of the slot showing up — before a human could even see it on screen. The 90-second timeout stops polling if nothing is released.

What is Auto-Book?

When enabled alongside Sniper Mode, the bot will automatically submit the booking the instant a matching slot is found — no manual intervention needed. If the course uses reCAPTCHA (like Sunken Meadow or Bethpage), you'll also need an Anti-Captcha API key so the CAPTCHA is pre-solved during the countdown and ready to submit with the booking.

What is the Booking Class?

ForeUp courses offer different booking classes (e.g., Resident, Non Resident, Verified NYS Resident) with different pricing and availability. After connecting, the dropdown populates with the options for your course. Pick the one that matches your status to see the right times and prices. "Auto-detect" tries unprotected classes first.

What does the Release Time mean?

This is the time your course publishes new tee times — for example, many NY state courses release at 7:00 PM for the following week. Set this to match your course's release schedule. The sniper arms early, pre-warms your session at T-5 seconds, and starts polling at exactly this time.

Sniper timeline

T-120s — Authenticate & pre-solve CAPTCHA
T-5s — Re-warm session (fresh cookies + JWT)
T-0s — Start polling every 200ms
T+match — Slot found → book instantly or alert
T+90s — Timeout if no slots found
