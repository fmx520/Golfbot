# Golfbot Frontend MVP

This is a speed-first single-page MVP built with Next.js + Tailwind and lightweight shadcn-style UI primitives.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Scope

- Single-page workflow with query input and run button.
- Output panel for live run events (currently placeholder events).
- Minimal UI intended to wire into backend stream endpoints in the next phase.
